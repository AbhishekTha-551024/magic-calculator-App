# Magic Calculator App

An advanced Android Magic Calculator application.

## Features
- Interactive Calculator with hidden magic tricks and secret features
- Custom screen lock simulation (MoiLock)
- Firebase authentication & Firestore sync support
- Modern Android UI with Kotlin and ViewBinding

## Tech Stack
- **Language**: Kotlin
- **SDK**: Target API 34 / Min API 23
- **Architecture**: Android Jetpack, ViewBinding, Coroutines, ViewModel
- **Backend Services**: Firebase Auth, Firestore
